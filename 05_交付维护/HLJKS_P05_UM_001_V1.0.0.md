## 1. 产品简介

1.1 黑龙江省考 AI 出题 Agent:两种方式生成行测模拟题——直接打字说需求(自然语言),或通过表单选择参数(可视化)。所有题目统一结构输出,可作答、看解析、查学习统计。

## 2. 页面结构

| 区域 | 内容 | 说明 |
|---|---|---|
| 顶部 | 标题栏 | 产品名 + 当前状态 |
| 输入区 | 双入口 Tab | ①对话式输入框 ②表单(模块/难度/题量/知识点/排除题) |
| 题目区 | 题目卡片 | 题干、4 选项,选项可点击作答 |
| 结果区 | 结果面板 | 判题正确/错误、解析、按钮「再来一道」 |
| 统计区 | 学习面板 | 总作答、正确率、薄弱点 |

## 3. 操作指引

### 3.1 自然语言出题
1. 切到「对话」入口。
2. 输入,如:`来 1 道资料分析题,关于增长率的`。
3. 提交;系统解析模块/难度/题量并出题。
4. 语义不完整时按默认(资料分析/中等/3 题)出题;数字只认阿拉伯数字。

### 3.2 表单出题
1. 切到「表单」入口。
2. 选择模块(言语/资料/判断/数量/常识)、难度、题量(1~10)。
3. 可填知识点、选择要排除的题(本次演示含内置排除能力)。
4. 提交;参数非法时返回明确提示,不静默出错。

### 3.3 作答与判题
1. 点击选项 A~D 作答。
2. 系统立即判定,展示解析与正确答案。
3. 点击「再来一道」生成不与本次重复的新题。

### 3.4 学习统计
1. 统计按浏览器本地保存(localStorage),同一浏览器持续累计。
2. 面板显示:作答总数、答对数、正确率(保留 1 位小数)、薄弱点(≤2 项,样本 <3 标注 insufficient)。

## 4. 常见问题 (FAQ)

| # | 问题 | 回答 |
|---|---|---|
| 1 | 为什么「一道」会出 3 题? | 目前只识别阿拉伯数字,中文数量词回落默认 3 题(已知限制) |
| 2 | 答案是不是提前藏在页面里? | 否;答案由服务端本地保存,随题面只下发空值(C2 强制约束) |
| 3 | 没有配置 AI Key 能用吗? | 能;自动走内置 Mock 题库(29 题),可完整演示 |
| 4 | 清除浏览器数据会怎样? | 学习统计清零,不影响出题 |
| 5 | 提交后按钮点了没反应? | 请求期间按钮禁用以防连点,等待响应即可;网络异常会提示 |
| 6 | 如何配置真实 AI? | 见 README §4/`server/.env.example`,配置 LLM_API_KEY 等三个变量 |

## 5. 异常处理

| 场景 | 表现 |
|---|---|
| 后端未启动 | 前端提示服务不可用(错误归一 503 语义) |
| LLM 超时 | 30s 超时重试 2 次,仍失败走 Mock 兜底 |
| 表单参数非法 | 明确错误码提示(ILLEGAL_MODULE 等) |
