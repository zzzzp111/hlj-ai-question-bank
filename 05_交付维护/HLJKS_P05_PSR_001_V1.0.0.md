## 4. 经验教训

| # | 教训 | 应对 |
|---|---|---|
| 1 | 3 小时时限内不应依赖真实 LLM 调试 | 双轨 Mock,基线与加分解耦 |
| 2 | 显式参数必须有严格校验(400)而非静默回落 | `_validateExplicitOverrides` 独立函数 |
| 3 | 前端要"按钮必须有用"的原子性检查 | Wave C 清理,6 处事件逐一核对 |
| 4 | 中文输入解析边界大 | 白名单+别名+有定义回落 |
| 5 | 文档滞后于代码会失真 | Wave 7 以实测数据回填文档族 |
| 6 | reactive 与 ref 取值语法不可混用,组件内部交互缺陷 e2e 覆盖不到 | Wave 8 最终验证代码走查兜出 BUG-009 并最小修复;含 UI 交互的函数列入交付前走查清单 |
