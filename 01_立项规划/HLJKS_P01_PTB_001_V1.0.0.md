## 2. 研制目的

面向黑龙江省考行测考生提供**智能刷题 Demo**：用户以自然语言或可视化配置提出练习需求 → Agent 出题（统一结构化 JSON）→ 用户作答 → 系统判题并展示解析。核心目标是验证"自然语言入口 + 可视化入口 → 统一结构化输出"的产品闭环，可无外部依赖（无 LLM Key）完整演示。
