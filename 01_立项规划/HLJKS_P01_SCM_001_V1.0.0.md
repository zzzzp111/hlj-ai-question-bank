## 4. 变更控制流程（CCB 语义，单人项目简化为"主 Agent 裁决"）

1. 提出变更（描述影响面：代码 / 接口 / 文档）。
2. 影响评估：接口或数据结构变更必须先同步 `docs/API.md`、`docs/DATA_SCHEMA.md` 再继续开发（AGENTS.md §6）。
3. 实施 + 原子验证（verify / e2e / build 全绿才可关闭变更）。
4. 记录：AI-CODING.md 错误表 / REGRESSION.md / 本文档族版本升修订号。
